采集与导出

采集规则与列说明

遍历全部 IAM 项目的「模型推理接入点」，写入新的时间戳 Excel（工作表名 火山云）。 不会写入或修改 ai网关令牌及渠道列表_*.xlsx。 TPM/RPM（TPM 在前）优先取接入点自定义限流；否则按基础模型匹配 ListModelRateLimit。 API Key = 该接入点匹配到的方舟密钥明文。默认 prd/prod、uat/dev、test/demo 分别互通。 若同一项目同时有 uat Key 和 dev Key，则 uat 只对 uat、dev 只对 dev。 对不上或没有环境词时，默认用项目里最老的一把明文 Key。 没有 test Key 时，test 接入点改用 uat/dev，不会误挂到 prd；uat/dev 不会去抢 test Key。 项目里只有一把环境 Key、其余是通用 Key 时：该环境只把最新接入点挂到这把 Key，旧接入点仍用通用 Key。 若 excel/火山真实数据.xlsx 存在，采集后按部署名把 API Key 改成真实表里的值。 表末 API Key汇总 列出该项目下全部「名称 | API Key」（对齐控制台「查看 API Key」），同一项目各行内容相同，方便查询。 最后一列 部署时间 取接入点 CreateTime；没有则从部署名 ep-YYYYMMDDHHmmss 解析。 「项目方」按控制台约定写成 项目名-负责人；没有负责人时填 N/A（如 AI-Drug-Research-N/A）。「联系人」同步取负责人，没有则为 N/A。

采集规则与列说明

同一套服务主体可扫多个订阅：subscription_ids 每行一个 GUID，Excel「订阅」列按顺序写成订阅1、订阅2…。 每个订阅的 IAM 都要给该应用加通用读者和认知服务用户（Cognitive Services User，拉密钥一）。 账号标记名 1 会写入「项目」「负责人」（按最后一个 - 拆开，项目名可含多个 -，负责人在最后；多人可用 ， / , / 、）；没有标记 1 则两列均为 N/A。功能/备注不采集。 调用 ARM：Accounts.list → Deployments.list → listKeys。 写入 excel/上游信息_Azure_时间戳.xlsx，工作表 Azure OpenAI。 列：订阅 / 区域 / Azure OpenAI / 部署名 / 模型名 / 模型版本 / 部署类型 / TPM / RPM / 接口 / 密钥一 / 项目 / 负责人 / 部署时间。
