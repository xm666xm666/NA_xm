上游账单

火山云 / Azure 按账期拉取上游账单。可选起止月份，每月各写一份 Excel（不把多月并进同一文件）。可一次采集火山云 + Azure写入同一工作簿（四张费用表），也可按厂商单独导出。 费用列标注 费用（¥），表末行为 SUM 合计。 火山云列：日期、项目名、产品、配置名称、分拆项ID、费用（¥）。 Azure 列：日期、项目名、项目负责人、模型名、配置名称、地区、订阅、费用（¥）。

导出：excel/上游账单_汇总_9月_年月日时分秒.xlsx

全部账单汇总

依次采集火山云与Azure OpenAI，写入同一工作簿 （火山云-按天、火山云-按月、Azure-按天、Azure-按月）。 凭证用各厂商页已填内容或 env/sites.json。一侧失败仍保留另一侧。 账期起止相同则只导出一个月；跨月则每月一份汇总表，一次最多 24 个月。

下载前先选文件。建议保留 30 天，系统不自动删除。

Azure OpenAI

服务主体与账期

使用 Entra ID 应用注册，调用 Cost Management Query API（分组依据资源）。 可本页手填，或在 env/sites.json 填写 upstream.azure。 账期起止跨月时每月各写一份 Excel，一次最多 24 个月。

采集与导出

采集规则与列说明

对照 成本分析 ：分组依据资源，粒度每天；按月由按天汇总。不是下载门户 xlsx。 项目名、项目负责人来自账号标记 1（按最后一个 - 拆开，负责人在最后一段）。 每个订阅须给该应用加「成本管理读取者」。 列：日期、项目名、项目负责人、模型名、配置名称、地区、订阅、费用（¥）；末行 SUM。
