Overview

工作台 + 原有模块

顶栏以 Web 应用为准：工作台 / 智能提取 / 批量配置 / 数据汇总 / 上游信息 / 一表总览 / 智能体（去掉原 ①②③⑤⑥ 序号）。批量配置、数据汇总、上游信息、一表总览、智能体以 iframe 嵌入，主题与连接状态跨页同步。

工作台

工作台

待办、认证状态、最近产物；三条任务卡进入接入 / 数据汇总 / 一表总览。

智能提取

智能提取

渠道或令牌双模式：杂乱文本 / 完整行 / 名-人拼接。渠道可选 LLM；结果一键填入批量配置。

批量配置

批量配置

渠道创建与安全删除、令牌、分组、按上游/类型/ID 启停、使用日志。env 快捷切环境。

数据汇总

数据汇总

多站全量采集生成时间戳 Excel；同页多站渠道余额查询；历史文件可选择下载。

上游信息

上游信息

火山云 / Azure OpenAI 采集，与数据汇总表相互独立，供一表总览对照。

一表总览

一表总览

选择数据汇总与上游生成总览；页内建议表勾选预禁用；宽限期与用量阈值可配置。

智能体

智能体

异步 Jobs + SSE、可视化计划、提取确认门禁、取消/重试；兼容同步 /api/agent/run。

工作台

默认落地工作台

打开应用即见待处置数量与三条固定任务。无分析表时待办卡引导去生成卫生建议，而不是显示假 0。路由 #workspace。

智能提取

智能提取

页面可切换渠道 / 令牌模式。渠道：规则引擎识别火山、Azure、自定义，可选 LLM；令牌：名-人拼接纯规则，无 LLM。

渠道：名称 [Tab] 分组 [Tab] 类型 [Tab] 模型… 令牌：名-人 [Tab] 分组 [Tab] 模型限制
能力说明
双模式channel / token（na_extract_mode）
类型识别火山 / Azure / 自定义
一键填入渠道→渠道管理 · 令牌→令牌管理
连接同步NA 地址与认证一并传递
LLM仅渠道且勾选时调用
批量配置

批量配置

连接 NA 后完成渠道、令牌、分组、启停与日志。删除两步确认；配置 env/sites.json 后可一键切 test/uat/prod。

渠道管理

批量创建与预删确认删；类型识别去重；示例锁定防误触。

渠道启停

按上游模型 / 类型全部 / 勾选 ID 启用禁用；可视化清单。

令牌管理

批量创建、模型限制、导出名称+密钥；可接令牌智能提取。

分组 · 日志

分组批量（需 Root）；使用日志按时间导出 CSV/Excel。

连接与认证

账号/Token · 会话缓存约 120s · URL 自动规范化。

权限建议

渠道 / 令牌 / 启停 / 日志用 Admin；分组用 Root。

数据汇总

数据汇总

配置多个 NA 站点（可从 env/sites.json 载入），一键拉取渠道与令牌。每次采集生成新时间戳文件（不自动建空模板）。同页支持多站点渠道已用/剩余余额查询与分表导出。

规则说明
分页拉取渠道 status=all 全状态，直至 total 收齐
排序各环境主表按 ID 升序
同名渠道按 ID 区分，不因名称覆盖
重复检测跨环境同名写入「重复模型」表，主表不删
余额查询已用/剩余 · 按环境分表（如 uat-渠道余额）
输出路径excel/ai网关令牌及渠道列表_YYYYMMDDHHmmss.xlsx

工作表包括各环境渠道/令牌主表与「重复模型」对照。令牌字段不全时自动调详情 API 补全。

智能体

全流程智能体

智能体为异步任务入口：LLM 规划、可视化步骤、提取确认门禁、SSE 真进度、取消/重试。连接与批量配置共用配置；CI 可用兼容接口 POST /api/agent/run。顶栏不再使用序号。

能力说明
异步 JobsPOST /api/agent/jobs · SSE /events · cancel / retry / confirm
LLM 规划最终步骤 = 用户勾选 ∩ LLM 计划（可回退规则）
人工门禁提取后可编辑渠道行再批量（Web 默认开启）
批量写入连接 NA 网关并创建渠道（支持测连 / Token）
多站汇总站点卡片与汇总 Tab 同步 localStorage
试运行dry_run 不写网关/Excel
兼容 APIPOST /api/agent/run · 同步等到终态 · 返回 job_id
curl -X POST http://127.0.0.1:8765/api/agent/run \ -H "Content-Type: application/json" \ -d '{"goal":"提取并写入uat","raw_text":"…","llm_api_base":"https://…","options":{"dry_run":true}}'
Experience

界面与主题

统一视觉由 na-theme.css 驱动，默认暗色主题。右上角可切换明亮模式，iframe 子页通过 postMessage 同步。表单与连接状态持久化至 localStorage。

Deploy

快速启动

项目要求
Python3.8+
依赖flask · requests · openpyxl
端口8765（可 --port 自定义）

Windows：

run.bat

Linux / macOS：

chmod +x run.sh && ./run.sh

复制整个项目目录即可独立部署，脚本自动创建虚拟环境并安装依赖。
